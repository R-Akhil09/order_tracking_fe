Order Tracking System – Frontend

This repository contains the frontend of the Order Tracking System built using React.js.

Frontend Repository: https://github.com/R-Akhil09/order_tracking_fe

Technologies Used : 
React.js, React Router, Axios, HTML, CSS, JavaScript

Features : 
Admin Login Authentication , 
Orders Dashboard with filters , 
Create New Order , 
View Order Details , 
Update Order Status , 
View Completed Orders 

How to Run : 
1. Clone the repository , 
2. Run npm install , 
3. Run npm start , 
4. Open http://localhost:3000
